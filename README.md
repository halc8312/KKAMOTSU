## ビルドと確認

Node.js 22以上を使用します。外部依存はないため、パッケージのインストールは不要です。

```bash
npm test
npm run build
```

公開用のファイルが `dist/` に出力されます。Python 3がある環境では、以下でローカル確認ができます。

```bash
python3 -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000/` を開いてください。ファイルを直接ダブルクリックする確認方法では、ルート相対リンクが正しく動作しません。

## XServerへの設置

1. 独自ドメインを取得し、XServerのサーバーパネルに追加します。
2. ドメインのネームサーバーまたはDNSを契約サーバーに向けます。
3. `SITE_BASE_PATH` を設定せず `npm run build` を実行します。
4. **`dist/` の中身**を、対象ドメインの `public_html/` にアップロードします。`public_html/index.html` になる配置です。
5. 無料独自SSL・HTTPS転送を設定し、ホーム・会社情報・募集・お問い合わせを確認します。
6. スマートフォンでLINEと電話のリンクを確認します。

XServerのWebサーバーにNode.jsやWordPressをインストールする必要はありません。リポジトリ全体ではなく、`dist/` 内の公開ファイルだけを設置します。

独自ドメインはまだこのリポジトリに固定していません。契約情報・FTPパスワードなどはコミットしないでください。

## GitHub Pages

既存のGitHub Pagesワークフローを静的サイト用に更新しています。`main` へのpushでテスト・ビルド・公開が実行され、PRではテストとビルドを実行します。

- GitHubのSettings → Pagesで、公開元をGitHub Actionsに設定します。
- Pagesの実際の公開パスを `actions/configure-pages` から取得し、ビルド時だけ内部リンクに反映します。
- サブディレクトリ用のローカルビルド例: `SITE_BASE_PATH=/KKAMOTSU npm run build`
- XServer用に戻すときは `SITE_BASE_PATH` を外して再ビルドしてください。

GitHubへの変更は、現在のChatGPT SitesやXServerに自動反映される設定ではありません。これらの公開先へは、確認した変更を別途デプロイ・アップロードします。
