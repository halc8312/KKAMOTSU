## ビルドと確認

Node.js 22以上を使用します。外部依存はないため、パッケージのインストールは不要です。

```bash
npm test
npm run build
```

公開用のファイルが `dist/` に出力されます。Python 3がある環境では、以下でローカル確認ができます。

```bash
python3 -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000/` を開いてください。ファイルを直接ダブルクリックする確認方法では、ルート相対リンクが正しく動作しません。

## XServerへの設置

1. 独自ドメインを取得し、XServerのサーバーパネルに追加します。
2. ドメインのネームサーバーまたはDNSを契約サーバーに向けます。
3. `SITE_BASE_PATH` を設定せず `npm run build` を実行します。
4. **`dist/` の中身**を、対象ドメインの `public_html/` にアップロードします。`public_html/index.html` になる配置です。
5. 無料独自SSL・HTTPS転送を設定し、ホーム・会社情報・募集・お問い合わせを確認します。
6. スマートフォンでLINEと電話のリンクを確認します。

XServerのWebサーバーにNode.jsやWordPressをインストールする必要はありません。リポジトリ全体ではなく、`dist/` 内の公開ファイルだけを設置します。

独自ドメインはまだこのリポジトリに固定していません。契約情報・FTPパスワードなどはコミットしないでください。

## GitHub Pages

既存のGitHub Pagesワークフローを静的サイト用に更新しています。`main` へのpushでテスト・ビルド・公開が実行され、PRではテストとビルドを実行します。

- GitHubのSettings → Pagesで、公開元をGitHub Actionsに設定します。
- Pagesの実際の公開パスを `actions/configure-pages` から取得し、ビルド時だけ内部リンクに反映します。
- サブディレクトリ用のローカルビルド例: `SITE_BASE_PATH=/KKAMOTSU npm run build`
- XServer用に戻すときは `SITE_BASE_PATH` を外して再ビルドしてください。

GitHubへの変更は、現在のChatGPT SitesやXServerに自動反映される設定ではありません。これらの公開先へは、確認した変更を別途デプロイ・アップロードします。

## 検索で見つけてもらうための設定

「沖縄 軽貨物 求人」などで探している人に届くよう、次の設定を入れています。

- **公開URLは1か所で管理**: `site-pages.json` の `siteUrl`。正規URL（canonical）、共有画像、構造化データ、`sitemap.xml`、`robots.txt` がこのURLで出力されます。独自ドメインへ移すときは、ここを書き換えて再ビルドしてください（一時的に変える場合は `SITE_URL=https://example.jp npm run build`）。
- **HTML内の `%SITE_URL%`**: ビルド時に公開URLへ置き換わります。消さないでください。
- **確認用のコピーは検索対象外**: `SITE_BASE_PATH` を付けたビルド（GitHub Pages）は自動で `noindex` になり、サイトマップも出力しません。公開サイトと内容が重複して評価が分散するのを防ぐためです。`SITE_NOINDEX=true` / `false` で明示的に切り替えられます。
- **タイトル・説明文・見出し**: 「沖縄」「那覇」「軽貨物ドライバー」「求人・募集」を、掲載済みの事実の範囲で入れています。
- **構造化データ**: 会社情報（LocalBusiness）、サイト名（WebSite）、パンくず（BreadcrumbList）、募集ページのよくある質問（FAQPage）。「よくある質問」の文言を変えたら、同じページの `application/ld+json` 内の文言も合わせてください。
- **求人用の構造化データ（JobPosting）**: 募集ページに入れています。Googleの求人検索枠に表示される可能性があります（表示はGoogleの判断で、保証はされません）。
  - 文言は必ずページ上の表示と一致させてください。ずれるとテストが失敗します。
  - Googleは「応募者の支払いが必要な求人」を認めていません。FC料は報酬から差し引く形で応募時の費用はないため掲載していますが、Search Consoleで「手動による対策」の通知が来た場合は、募集ページの `JobPosting` のブロックを削除してください。
  - 募集を終了したら、`JobPosting` のブロックを削除してください（期限切れの求人を残すことは認められていません）。
  - 給与欄（`baseSalary`）は入れていません。月間売上の例は基本給ではないためです。
- **共有画像**: `assets/og-image.jpg`（ホーム写真から作成、1200×630）。LINEなどで共有したときに表示されます。

### サイトの外で行うこと（リポジトリでは設定できません）

1. **Google Search Console** に公開URLを登録し、`sitemap.xml` を送信する。所有権確認用のタグが発行されたら、各ページの `<head>` に追加します。
2. **Googleビジネスプロフィール** を作成・整備する（社名・住所・電話番号はサイトと同じ表記に統一し、サイトURLを登録）。「那覇 軽貨物」など地域の検索と地図に表示されやすくなります。
3. **独自ドメイン** を取得したら `siteUrl` を変更し、旧URLから転送する。
4. **求人サイト**（Indeed・求人ボックスなど）へ掲載する場合は、FC料など応募者の費用負担に関する各社の掲載基準を事前に確認する。
5. LINE公式アカウントやSNSのプロフィールに、募集ページのURLを載せる。
